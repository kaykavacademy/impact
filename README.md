# KayKav Builder Impact

A clickable prototype of the **Impact Measurement Framework v1**, served via
GitHub Pages from `index.html` at the repository root.

## What this is

This is a front-end prototype only — a single self-contained HTML page you can
click through to explore how the framework presents programmes, cohorts,
participants, and outcomes. There is no backend, database, or live data feed.

## About the data

- **Usage and revenue figures are placeholder data.** They are illustrative
  only and do not reflect real measurements.
- **Cohort dates, participant names, and product names come from programme
  records.**

## Viewing it

Once GitHub Pages is enabled for this repository, the prototype is available at
the published Pages URL. You can also open `index.html` directly in a browser.
